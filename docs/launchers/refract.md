# Refract

Refract 是由 [RefractMC](https://github.com/RefractMC) 维护的现代开源 Minecraft 启动器，基于 Tauri、React 与 Rust 构建，官方介绍为具有可高度自定义的界面引擎，并原生集成 Modrinth 与 CurseForge 内容平台。

![Refract](https://refractmc.net/images/screenshots/library.png)

> 信息更新时间：2026-08-01

| 特性 | 详情 |
| --- | --- |
| 认证方式 | Microsoft 账户 / 离线账户 / 第三方皮肤站账户 |
| 支持的模组加载器 | Forge / NeoForge / Fabric / Quilt |
| 支持平台 | Windows / macOS / Linux |

## 特色功能

- 实例管理：创建、分组、复制、导出、置顶、搜索与筛选实例，并可导入已有的 MultiMC 或 Prism 实例库
- 内置 Modrinth 与 CurseForge 内容浏览，可安装模组、整合包、光影、资源包与数据包，自动解析依赖并支持保存可复用的模组档案
- 世界与备份管理、截图浏览以及实时服务器状态追踪
- 自动查找或下载合适的 Java 运行时，支持自定义 JVM 参数与内存分配
- 支持自动更新与崩溃报告复制
- 可自定义主题、强调色与侧边栏布局
- 支持 Discord Rich Presence 与 Java Edition 许可证验证
