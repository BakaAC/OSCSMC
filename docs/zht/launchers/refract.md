# Refract

Refract 是由 [RefractMC](https://github.com/RefractMC) 維護的現代開源 Minecraft 啟動器，基於 Tauri、React 與 Rust 構建，官方介紹為具有可高度自訂的介面引擎，並原生整合 Modrinth 與 CurseForge 內容平台。

![Refract](https://refractmc.net/images/screenshots/library.png)

> 資訊更新時間：2026-08-01

| 特性 | 詳情 |
| --- | --- |
| 認證方式 | Microsoft 帳戶 / 離線帳戶 / 第三方皮膚站帳戶 |
| 支援的模組載入器 | Forge / NeoForge / Fabric / Quilt |
| 支援平台 | Windows / macOS / Linux |

## 特色功能

- 實例管理：建立、分組、複製、匯出、置頂、搜尋與篩選實例，並可匯入已有的 MultiMC 或 Prism 實例庫
- 內建 Modrinth 與 CurseForge 內容瀏覽，可安裝模組、整合包、光影、資源包與資料包，自動解析依賴並支援儲存可重複使用的模組檔案
- 世界與備份管理、截圖瀏覽以及即時伺服器狀態追蹤
- 自動尋找或下載合適的 Java 執行環境，支援自訂 JVM 參數與記憶體配置
- 支援自動更新與崩潰報告複製
- 可自訂主題、強調色與側邊欄版面
- 支援 Discord Rich Presence 與 Java Edition 授權驗證
