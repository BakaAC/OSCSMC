# Refract

Refract is a modern, open-source Minecraft launcher maintained by [RefractMC](https://github.com/RefractMC), built with Tauri, React, and Rust. It is officially described as featuring an ultra-customizable UI engine and native Modrinth and CurseForge integration.

## Features

- Instance management with create, group, duplicate, export, pin, search, and filter, plus import of existing MultiMC or Prism libraries
- Built-in Modrinth and CurseForge browsing to install mods, modpacks, shaders, resource packs, and datapacks, with automatic dependency resolution and reusable mod profiles
- World and backup management, screenshot browsing, and live server status tracking
- Automatic Java discovery and download, with custom JVM arguments and memory settings
- Automatic updates and crash-report copying
- Customizable themes, accent colors, and sidebar layouts
- Discord Rich Presence and Java Edition license verification
